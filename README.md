
# FINsight — Unified Intelligent Financial Management Platform

FINsight is a unified financial management platform designed to combine simulated digital payments, expense tracking, budgeting, financial planning, analytics, and AI-powered financial assistance in one application.

## Project Overview

The platform provides tailored financial experiences for four user profiles:

1. Personal / Individual
2. Business
3. Freelancer / Professional
4. Merchant

An administrative interface supports platform monitoring and management.

## Core Features

- Simulated wallet and virtual account management
- Simulated money transfers and QR payments
- Transaction history and payment tracking
- Expense and income management
- Budget planning and savings goals
- Financial health score and safe-to-spend calculations
- Financial analytics and reports
- Bill payment and autopay simulation
- Insurance policy management
- Simulated gold investment tracking
- AI-powered financial insights and assistance
- Notifications and financial alerts
- Profile-specific dashboards and experiences

## Academic Project Scope

FINsight version 1 implements a simulated financial ecosystem.

No real-money transfers, live banking integrations, actual gold trading, or real investment execution are performed.

These integrations may be considered future enhancements.

## Technology Stack

- Flutter
- Dart
- Riverpod
- GoRouter

## Architecture

The application follows a feature-first architecture with shared components, centralized theme configuration, responsive layouts, and structured navigation.

## Supported Platforms

- Android
- iOS
- Web
- macOS

## Development Status

Currently under development. The initial phase focuses on the frontend, navigation, reusable components, responsive layouts, and simulated interactions.
